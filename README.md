# 📖 Overview

PhishSafeguard is a web-based cybersecurity platform developed as a Final Year B.Tech (CSE) project at the **Global Institute of Management & Technology (GIMT), Krishnanagar**.

The platform is designed to detect phishing websites before users interact with them by combining **Artificial Intelligence**, **Machine Learning**, and **Rule-Based Security Analysis**. It performs multi-layer URL inspection, evaluates security indicators, and generates explainable threat reports to minimize phishing attacks, credential theft, and online fraud.

# 🏗️ System Architecture

The platform follows a multi-layer detection pipeline:

1. URL Validation
2. Feature Extraction
3. Rule-Based Security Analysis
4. Machine Learning Prediction
5. SSL & Domain Verification
6. Risk Score Calculation
7. Threat Classification
8. Report Generation

Final classifications include:

- ✅ Safe
- ⚠️ Suspicious
- ❌ Phishing

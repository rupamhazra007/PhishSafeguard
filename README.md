# 🛡️ PhishSafeguard – AI Powered Phishing URL Detection System

PhishSafeguard is a Final Year B.Tech (CSE) project developed at the Global Institute of Management & Technology (GIMT), Krishnanagar.

The system is designed to detect phishing websites using Artificial Intelligence, Machine Learning, and Rule-Based URL Analysis. It helps users identify malicious URLs before visiting them, reducing the risk of phishing attacks, identity theft, and online fraud.

## 📊 Detection Workflow

1. User enters a URL.
2. URL format is validated.
3. URL features are extracted.
4. Rule-based analysis is performed.
5. Machine learning model predicts the result.
6. SSL and domain information are verified.
7. Risk score is calculated.
8. Final result is displayed as:
   - ✅ Safe
   - ⚠️ Suspicious
   - ❌ Phishing

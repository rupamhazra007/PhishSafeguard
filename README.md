# 📖 Overview

**PhishSafeguard** is a web-based cybersecurity platform developed as a **Final Year B.Tech (Computer Science & Engineering)** project at **Global Institute of Management & Technology (GIMT), Krishnanagar**, affiliated with **MAKAUT, West Bengal**.

The platform is designed to detect phishing websites before users interact with them by combining **Artificial Intelligence**, **Machine Learning**, and **Rule-Based Security Analysis**.

Unlike traditional blacklist-based phishing detectors, PhishSafeguard performs **multi-layer URL inspection**, analyzes multiple security indicators, evaluates SSL certificates, verifies domain reputation, calculates risk scores, and generates explainable threat reports to help users make informed security decisions.

The primary objective is to reduce phishing attacks, credential theft, financial fraud, and identity theft through intelligent and real-time phishing detection.

# 🏗️ System Architecture

The phishing detection pipeline follows a hybrid security model.

```
User Input URL
        │
        ▼
URL Validation
        │
        ▼
Feature Extraction
        │
        ▼
Rule-Based Analysis
        │
        ▼
Machine Learning Prediction
        │
        ▼
SSL & Domain Verification
        │
        ▼
Risk Score Calculation
        │
        ▼
Threat Classification
        │
        ▼
Security Report Generation
```

The final output is classified as:

- ✅ Safe
- ⚠️ Suspicious
- ❌ Phishing

# 🚀 Detection Workflow

1. User enters a URL.
2. URL format is validated.
3. URL features are extracted.
4. Rule-based phishing checks are executed.
5. Machine Learning predicts the phishing probability.
6. SSL certificate and domain information are verified.
7. Risk score is generated.
8. Final classification is displayed.
9. Security report is generated.
10. Scan history is stored in the database.
